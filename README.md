# Python Fundamental Coding Problems

A collection of foundational programming, Data Structures & Algorithms (DSA), and logic-building problems. Detailed code implementations and executable solutions can be found in the accompanying Jupyter Notebook (`.ipynb`).

---

## Problem Overview

### 1. Two Sum
Given an array of integers `nums` and an integer `target`, return the indices of the two numbers such that they add up to the `target`. You may assume that each input would have exactly one solution, and you may not use the same element twice.

* **Sample Input:** `nums = [2, 7, 11, 15]`, `target = 9`
* **Expected Output:** `[0, 1]`

---

### 2. Palindrome Number
Given an integer `x`, determine whether it reads the same forward and backward. Return `True` if it is a palindrome, otherwise return `False`.

* **Sample Input:** `x = 121`
* **Expected Output:** `True`

---

### 3. Contains Duplicate
Given an integer array `nums`, determine whether any value appears at least twice in the array. Return `True` if any duplicate exists; otherwise, return `False`.

* **Sample Input:** `nums = [1, 2, 3, 4, 77, 34, 90, 23, 77]`
* **Expected Output:** `True`

---

### 4. Prime Number Check
Given a positive integer `N`, determine whether it is a prime number. Print `"Prime"` if it is a prime number; otherwise, print `"Not Prime"`.

* **Sample Input:** `N = 29`
* **Expected Output:** `"Prime"`

---

### 5. Second Largest Element
Given an array of integers, find the second largest distinct element in the array. If a second largest element does not exist, return `-1`.

* **Sample Input:** `nums = [10, 20, 40, 30, 40, -5, -4]`
* **Expected Output:** `30`

---

### 6. Valid Palindrome (String)
Given a string `s`, determine whether it is a palindrome. Ignore spaces, punctuation, and letter case while checking. Return `True` if it is a palindrome; otherwise, return `False`.

* **Sample Input:** `s = "A man, a plan, a canal: Panama"`
* **Expected Output:** `True`

---

### 7. Fibonacci Series Check
Write a program to accept a number from the user and verify whether it belongs to the Fibonacci series or not.

* **Input:** User-provided integer $N$
* **Expected Output:** Statement indicating whether $N$ is a Fibonacci number.

---

### 8. Find Missing Number (Sequence Pattern)
Given a sequence of cubic numbers with one value missing, identify and output the missing number.

* **Sample Input:** `[1, 8, 27, 64, 216]`
* **Expected Output:** `125`

### 10. Process List Elements (Even / Odd Logic)
Process the elements of a given list of integers by applying conditional transformations depending on whether each element is even or odd.

* **Sample Input:** nums = [2, 5, 8, 3, 10, 7]

* **Expected Output:** [1, 10, 4, 6, 5, 14]
